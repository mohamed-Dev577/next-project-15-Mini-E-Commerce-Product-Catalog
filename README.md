# 🛍️ Mini E-Commerce Product Catalog

## 📌 نبذة عن المشروع

مشروع **Mini E-Commerce Product Catalog** هو كتالوج منتجات بسيط يحاكي جزءًا من تجربة التسوق الإلكتروني، حيث يتيح للمستخدم استعراض مجموعة من المنتجات والبحث عنها بالاسم، بالإضافة إلى تصفيتها حسب التصنيف.

تم تطوير المشروع باستخدام **Next.js وReact** مع التركيز على التعامل مع البيانات وإدارة الحالة وتنفيذ البحث والفلترة بشكل تفاعلي.

## ✨ المميزات

* 🔍 البحث عن المنتجات باستخدام أسمائها.
* 🗂️ تصفية المنتجات حسب التصنيف.
* 🔄 الجمع بين البحث والفلترة في الوقت نفسه.
* ⚡ تحديث النتائج تلقائيًا عند تغيير البحث أو التصنيف.
* 📦 عرض اسم المنتج وسعره وتصنيفه.
* 🎯 واجهة بسيطة وسهلة الاستخدام.

## 🛠️ التقنيات المستخدمة

* **Next.js**
* **React**
* **JavaScript**
* **React Hooks**
* **useState**
* **Array Methods (filter & map)**

## ⚙️ آلية العمل

يعتمد المشروع على مجموعة من المنتجات المخزنة داخل مصفوفة، ويتم استخدام:

* `useState` لإدارة نص البحث والتصنيف المحدد.
* `filter()` لاختيار المنتجات المطابقة للشروط.
* `includes()` للتحقق من وجود نص البحث داخل اسم المنتج.
* `toLowerCase()` لجعل البحث غير حساس لحالة الأحرف.
* `map()` لعرض المنتجات المطابقة داخل الصفحة.

كما يمكن للمستخدم الجمع بين البحث بالاسم واختيار التصنيف للحصول على نتائج أكثر دقة.

## 🎯 الهدف من المشروع

تطبيق المفاهيم العملية في React وNext.js، وتطوير مهارات التعامل مع المصفوفات وإدارة الحالة وبناء وظائف البحث والتصفية التفاعلية.
